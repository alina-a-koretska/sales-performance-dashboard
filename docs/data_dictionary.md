# Data Dictionary

This document describes the dataset used throughout the project.

| Column | Description |
|---------|-------------|
| Order_ID | Unique identifier for each sales transaction |
| Order_Date | Date when the order was placed |
| Region | Country where the sale occurred |
| Customer_Segment | Customer category (Small Business, Mid-Market, Enterprise) |
| Product | Product purchased |
| Sales_Rep | Sales representative responsible for the sale |
| Units | Number of licenses sold |
| Unit_Price | Selling price per unit before discounts |
| Discount_Pct | Discount applied to the order (%) |
| Revenue | Revenue generated after applying the discount |
| Cost | Estimated delivery cost |
| Profit | Revenue minus Cost |
