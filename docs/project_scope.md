# Project Scope

## Project Goal

Analyse sales performance using transactional sales data to identify:

- Revenue drivers
- Profitability drivers
- Regional performance
- Customer segment performance
- Product performance
- Discount impact

The outcome of this project is a set of data-driven recommendations to support management decision-making.

## Success Criteria

This project will:

- Answer key business questions using SQL
- Present findings through clear visualisations
- Recommend practical business improvements
- Demonstrate a structured Business Analysis approach
