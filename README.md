# 📊 Sales Performance Dashboard

> A portfolio project demonstrating how sales data can be transformed into business insights using SQL, Excel, and dashboard reporting.

---

## 📌 Overview

This project analyses sales performance for a fictional software company.

The objective is not to calculate numbers, but to answer real business questions asked before making strategic decisions.

The dataset used in this project is synthetic and was created for portfolio purposes.

---

## 🎯 Business Objective

Management wants to understand:

- Which products generate the highest revenue?
- Which products generate the highest profit?
- Which regions perform best?
- Which customer segment is the most valuable?
- How do discounts affect profitability?
- What trends can be observed over time?

---

## 📈 KPIs

- Total Revenue
- Gross Profit
- Gross Margin
- Average Order Value
- Revenue by Region
- Revenue by Product
- Revenue by Customer Segment
